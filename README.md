# @defra/hapi-oidc-auth-defra-id

Reusable [Hapi](https://hapi.dev) plugin that adds **applicant sign-in via Defra
Customer Identity** (OpenID Connect auth-code + PKCE) to a CDP frontend.

> **Status: initial scaffold.** This repo is the **applicant (Defra Customer
> Identity)** half of the DEFRA sign-in plugins. The **case-officer** (Microsoft
> Entra ID) journey lives in a separate package, `@defra/hapi-oidc-auth`. The
> plugin implementation is being added via pull request.
